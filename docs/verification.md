# 公开版验证说明

- 自动化测试覆盖真实 SDK/STDIO MCP 子进程、本机测试 HTTP broker、测试命名管道、状态持久化、幂等安装与卸载、会话隔离和任务领取认证。
- 默认后台模式不打开或聚焦窗口、不使用剪贴板或模拟输入。MCP 的两个桌面兼容入口仅返回 background_only；手动 CLI 的 UI 诊断需要显式 --allow-ui。
- 开发过程中完成过真实 Claude Desktop Code 的只读任务往返及同会话后台追问。没有据此声称静默新建会话、切换模型或代码修改类任务均已验收。
- 新安装机器仍需分别验证：配置写入、MCP 加载、会话注册、实际领取、报告返回、Stop 后续派发。
- 公开版测试使用合成数据；不附带真实任务、领取密钥、用户配置或运行日志。
- npm test 会先构建，避免运行旧 dist。客户端更新后需重新验证版本相关的消息协议。
